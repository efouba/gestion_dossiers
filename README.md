Cette application web open-source permet de centraliser la gestion de vos projets. Conçue avec une architecture PHP et MySQL, elle permet de structurer vos dossiers, de créer des listes de tâches (To-Do) et d'automatiser le suivi de vos activités quotidiennes ou professionnelles. [1, 2, 3, 4] 
## 🌟 Fonctionnalités principales

* Gestion des dossiers : Regroupez vos tâches par catégories, départements ou projets spécifiques.
* Suivi des tâches (CRUD) : Ajoutez, modifiez, supprimez et marquez des tâches comme terminées.
* Tableau de bord : Vue d'ensemble des tâches en cours et des dossiers prioritaires.
* Stockage de documents : Possibilité d'associer des fichiers ou des documents aux dossiers pour un meilleur suivi.
* Recherche et filtres : Trouvez rapidement un dossier spécifique. [1, 2, 5, 6] 

## 🛠️ Technologies utilisées

* Backend : PHP (idéal pour traiter les formulaires et requêtes dynamiques).
* Base de données : MySQL.
* Frontend : HTML, CSS, JavaScript (pour une interface utilisateur interactive et fluide).
* Architecture : MVC (Modèle-Vue-Contrôleur) généralement adoptée pour structurer proprement le code. [2, 5, 7, 8] 

## ⚙️ Instructions d'installation

   1. Prérequis : Assurez-vous d'avoir un serveur local (comme [XAMPP](https://www.apachefriends.org/fr/index.html) ou [Laragon](https://laragon.org/)) installé sur votre machine.
   2. Cloner le projet : Téléchargez les fichiers sources ou utilisez la commande git pour cloner le dépôt :
   
   git clone [URL_DU_DEPOT_GITHUB]
   
   3. Base de données : Importez le fichier .sql (souvent fourni dans le dossier du projet) dans votre outil phpMyAdmin ou via la console.
   4. Configuration : Modifiez le fichier de connexion à la base de données (ex: config.php) pour y insérer vos identifiants locaux.
   5. Lancement : Déplacez le dossier du projet dans le répertoire de votre serveur (ex: htdocs pour XAMPP) et accédez à l'application via votre navigateur.
